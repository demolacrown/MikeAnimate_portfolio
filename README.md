# MikeAnimate — Stories in Motion

A responsive, single-page portfolio concept for an independent animation creator. Built with plain HTML, CSS, and JavaScript — no build tools or framework required.

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `mikeanimate-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub Pages finishes deploying, the site should be available at `https://demolacrown.github.io/mikeanimate-portfolio/`.

## Customise
- Update the GitHub profile link in `index.html` if needed.
- Replace the three CSS-built concept visuals with real project images when ready.
- Edit the project descriptions to match your actual work.

The project cards are concept placeholders, not claims of completed client projects.
